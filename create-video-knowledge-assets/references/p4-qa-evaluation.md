# P4 Q&A Evaluation

Evaluate a completed course-notes Q&A answer after validation.

- coverage: the answer addresses the question's supported selected facets; every factual claim maps to a selected plan block, evidence window, and source span.
- readability: blocks follow a clear question-oriented order, distinguish explicit video statements from inference, and make citations or time spans easy to inspect.
- limits: name missing facets, insufficient evidence, and video scope boundaries plainly. Do not replace a stated limit with unsupported detail or unlabelled external material.

Validation establishes reference integrity; this review checks whether the answer is useful and appropriately bounded.
